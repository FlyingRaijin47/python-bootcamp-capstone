## 6. Running the Streamlit Applications

Clone the repository:

```bash
git clone https://github.com/FlyingRaijin147/python-bootcamp-capstone.git
cd python-bootcamp-capstone
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the Day 6 assignment dashboard:

```bash
streamlit run dsa_assignmentday6_app.py
```

Run the original portfolio dashboard:

```bash
streamlit run app.py
```
